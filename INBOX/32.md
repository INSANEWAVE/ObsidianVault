# 🏋️ Трекер Рекомпозиции: Втягивание (Недели 1-2)

> [!info] 🎯 **Цель на 14 дней:** 
> Плавная адаптация мышц и ЦНС к силовым нагрузкам после перерыва. Фокус на технику, а не на отказ! Оставляем 2-3 повторения в запасе. 

## 📋 Базовые параметры
- **Цель:** Рекомпозиция (сжигание жира + рост мышц)
- **Стартовый вес:** 83-85 кг
- **Ежедневное кардио:** 🚶‍♂️ 40 мин (3.3 км) с рюкзаком (4-5 кг).
- **Схема тренировок:** ПН-СР-ПТ (30 мин железо + 30 мин груша).

## 🗓️ НЕДЕЛЯ 1: Адаптация

### Понедельник: Тренировка А (Грудь, Ноги, Пресс) + Груша
- [x] 🚶‍♂️ Пешком с работы (3.3 км, рюкзак)
- [x] **Жим штанги лежа (Скамья):** 
  - [x] Разминка: пустой гриф (20 кг) х 15 повторений
  - [x] Рабочие: 3 подхода x 10-12 повторений (Целевой вес: `30-40` кг) | Отдых 90 сек
- [x] **Гоблет-присед (с гирей/гантелей на груди):** 
  - [x] 3 подхода x 12 повторений (Целевой вес: `12-16` кг) | Отдых 90 сек
- [x] **Подъем прямых ног в тренажере:** 
  - [x] 3 подхода x 10-15 повторений (свой вес) | Отдых 60 сек
- [x] 🥊 **Груша (30 мин):**
  - [x] 5 мин: Легкий бой с тенью
  - [x] 20 мин: Отработка связок (раунды 3 мин работа / 1 мин отдых)
  - [x] 5 мин: Заминка и растяжка

### Среда: Тренировка Б (Спина, Плечи, Взрывная сила) + Груша
- [ ] 🚶‍♂️ Пешком с работы (3.3 км, рюкзак)
- [ ] **Тяга гантели к поясу в наклоне (опора на скамью):**
  - [ ] 3 подхода x 10-12 повторений на каждую руку (Целевой вес: `10-14` кг) | Отдых 90 сек
- [ ] **Жим гантелей сидя (Плечи):**
  - [ ] 3 подхода x 10-12 повторений (Целевой вес: `8-12` кг в каждую руку) | Отдых 90 сек
- [ ] **Махи гирей перед собой (Kettlebell Swings):**
  - [ ] 3 подхода x 15-20 повторений (Целевой вес: `16` кг) | Отдых 60 сек
- [ ] 🥊 **Груша (30 мин):** 
  - [ ] Формат: Свободная работа, фокус на передвижениях и уклонах.

### Пятница: Тренировка А (Грудь, Ноги, Пресс) + Груша
- [ ] 🚶‍♂️ Пешком с работы (3.3 км, рюкзак)
- [ ] **Жим штанги лежа:** 3 x 10-12 (Целевой вес: `30-40` кг)
- [ ] **Гоблет-присед:** 3 x 12 (Целевой вес: `12-16` кг)
- [ ] **Подъем прямых ног в тренажере:** 3 x 10-15 (свой вес)
- [ ] 🥊 **Груша (30 мин):**
  - [ ] Формат: Силовые одиночные/двойные удары, акцент на жесткость.
