
# Введение

### Выбор микроконтроллера
![[IMG20251205132913.jpg]]

В соответствии с заданием на индивидуальную работу был выполнен выбор микроконтроллера который позволит выполнить все пункты в технических требованиях:

#### Наличии интерфейса позволяющего передавать данные через Ethernet. 
Таким интерфейсом оснащены микроконтроллеры моделей STM32F107xx или STM32F407xx/ Встроенный интерфейс обозначается как RMII или MII Ethernet.

В качестве бюджетного варианта выбран контроллер STM32F107RCT6 в качестве бюджетного и компактного варианта. Микронтроллер, согласно литерам RCT, поставляется в корпусе LQFP64 и оснащён 256 Кб Flash-памяти.

Для экономии пинов мы будем пользоваться интерфейсом RMII, что потребует внешний кварцевый генератор на 50 МГц. Помимо этого для работы с портом Ethernet необходим PHY для физической передачи данных по проводу Ethernet.

## Особенности контроллера

Все пины GPIO (General Purpose Input/Output) являются "high-current capable" что означает возможность подключения маломощных индикаторных светодиодов напрямую. Это обеспечивает нам упрощение выполнения пункта ТЗ, требующего установить световую индикацию.

## Интерфейсы связи

### RMII Ethernet
Для связи с другими системами робота используется интерфейс RMII Ethernet

**MII** (Media Independent Interface — независящий от среды передачи интерфейс) - предшественник RMII (Reduced Media Independent Interface — сокращённый независящий от среды передачи интерфейс). MII - стандартизованный интерфейс для подключения [MAC](https://ru.wikipedia.org/wiki/Media_Access_Control "Media Access Control")-блока сети [Fast Ethernet](https://ru.wikipedia.org/wiki/Fast_Ethernet "Fast Ethernet") к блоку [PHY](https://ru.wikipedia.org/wiki/PHY "PHY"). Интерфейс MII может быть выведен на разъём для подключения внешнего приёмопередатчика или может просто соединять две микросхемы на одной печатной плате. В нашем случае в качестве PHY выступает микросхема LAN8720.

Независимость от среды передачи означает, что существует возможность использования любых PHY-устройств без необходимости смены или переработки аппаратуры MAC-блока.

Интерфейс MII состоит из двух частей: канала приёма-передачи данных (MII) и служебного канала управления (MDIO и MDC).

Все операции интерфейса MII выполняются в синхронном режиме.

В качестве сокращённого интерфейса применяется RMII отличающийся лишь уменьшением количества линий передачи данных вдвое, при этом обязательно увеличение частоты синхронизации вдвое, для обеспечения заявленных 100 Мбит/с
### SPI
Для внутренней связи используется интерфейс SPI.

**SPI** ([англ.](https://ru.wikipedia.org/wiki/%D0%90%D0%BD%D0%B3%D0%BB%D0%B8%D0%B9%D1%81%D0%BA%D0%B8%D0%B9_%D1%8F%D0%B7%D1%8B%D0%BA "Английский язык") Serial Peripheral Interface, SPI bus — последовательный периферийный интерфейс, шина SPI) — последовательный синхронный стандарт передачи данных в режиме полного [дуплекса](https://ru.wikipedia.org/wiki/%D0%94%D1%83%D0%BF%D0%BB%D0%B5%D0%BA%D1%81_\(%D1%82%D0%B5%D0%BB%D0%B5%D0%BA%D0%BE%D0%BC%D0%BC%D1%83%D0%BD%D0%B8%D0%BA%D0%B0%D1%86%D0%B8%D0%B8\) "Дуплекс (телекоммуникации)"), предназначенный для обеспечения простого и недорогого высокоскоростного сопряжения микроконтроллеров и периферии. SPI также иногда называют четырёхпроводным ([англ.](https://ru.wikipedia.org/wiki/%D0%90%D0%BD%D0%B3%D0%BB%D0%B8%D0%B9%D1%81%D0%BA%D0%B8%D0%B9_%D1%8F%D0%B7%D1%8B%D0%BA "Английский язык") four-wire) интерфейсом.

# Внешняя система тактирования

Для обеспечения наибольшей точности работы модуля был установлен отдельный высокочастотный генератор тактирования на основе кварцевого резонатора

Данное решение обусловлено нестабильностью встроенных в STM32 релаксационных генераторов, которые в силу своей природы имеют склонность к временным нестабильностям частоты а также неустойчивы к термическому воздействию из-за прямой интеграции элементов генератора в микроконтроллер которому свойствен нагрев при обработке данных и вычислениях. 

В качестве оптимального баланса между ценой и эффективностью был выбран вариант установки генератора на основе кварцевого резонатора по схеме Пирса

# Передатчик LAN 8720

Взаимодействие с роботом осуществляется через интерфейс ETHERNET что вынуждает нас использовать Ethernet PHY (Physical Layer Transceiver) поскольку используемый в системе микроконтроллер имеет встроенный Ethernet MAC но не имеет физического преобразователя для передачи данных напрямую по кабелю. 
 Для передачи сигналов была выбрана микросхема LAN 8720 работающая в связке с открытой библиотекой LWIP
 
 Обмен данными между LAN 8720 и Микроконтроллером идёт через RMII - межканальный интерфейс, требующий собственного тактирования в 50 Мегагерц, что необходимо для синхронной передачи данных и экономии портов без потери скорости передачи.

# Датчик движения HC-SR501

Данный датчик движения подаёт высокий сигнал при обнаружении движения в зоне сканирования. Система основана на инфракрасном пироэлектрическм детекторе LHI778 который примечателен своей дешевизной и простотой. Сам датчик имеет угол обзора в 71 градусов, но модуль использует линзу Френеля для увеличения угла работы датчика до 120 градусов.

![[Pasted image 20251205191119.png]]

Принцип работы датчика прост - два пироэлектрических кристалла воспринимают окружающее инфракрасное излучение, причём будучи подключёнными встречно-поледовательно они вычитают сигналы друг друга. Если в помещении куда смотрит датчик поднимется температура - ложного срабатывания не произойдёт, ведь сигнал на оба кристалла идёт один. Если мимо пройдёт человек, то Сигнал резко возрастёт на одном кристалле, а через некоторое время - на другом. Для обработки такого поведения PIR контроллер (BISS0001) фиксирует дифференциальный сигнал с пары датчиков, после чего уходит в небольшую задержку (ожидая повторного сигнала но на другом пирокристалле) и при получении следующего сигнала даёт данные о направлении движения человека.

![[Pasted image 20251205194022.png]]

Сам модуль, однако, работает только в режиме I/O что ограничивает нас в данных - мы можем лишь узнать, есть ли движение или его нет.
